MeshVisor

Repair scanned meshes in Blender, using the scan's own measurements.

What It Is

MeshVisor is a Blender add-on for the step between a 3D scan and a usable model. Photogrammetry and laser scans come out with holes where the camera could not see, flaps folded under themselves, scattered junk and an arbitrary scale. MeshVisor repairs them, and wherever it can, it repairs them from real measurements rather than from guesswork.

Its distinctive idea is a reference point cloud, typically a laser scan. You fit the photogrammetry mesh onto the cloud and read off its real scale. Then you rebuild damaged regions from the measured points and see how far the result is from them before you accept it. For holes with no reference data, a classic patch fills the gap, matching the triangle size, curvature and surface detail around it.

Hole only: Repair › Patch: select an edge of the hole → Mark Hole Boundary → Patch.
With a laser scan: Reference (load the cloud) → Align (Fit to Reference) → Repair › Rebuild (Rebuild & Repair → check the numbers → Accept Repair).

Physical models (contour boards, DXF, 3D-print bases) live in the separate add-on ModelVisor.

Philosophy

Measurements before inventions

A filled hole is a claim about a surface nobody saw. When a reference scan has real points there, MeshVisor rebuilds from them. When it has none, it says so and falls back to a patch that only continues the surrounding surface. The reconstructed area can carry its own material, the conservation convention for fills, so it stays identifiable later.

Grounded in the literature

The main algorithms come from published geometry-processing work: isotropic and curvature-adaptive remeshing, quadric error metrics, biharmonic fairing, Screened Poisson reconstruction, ICP with Umeyama's closed-form similarity, PCA normals. See Literature.

Preview, measure, then accept

Destructive steps show their result before they commit. Rebuild & Repair leaves its patch as a separate object with its deviation from the scan until you Accept or Reject it. Selection tools select, they do not delete. Every operator is undone with a single Ctrl+Z.

Simple first, everything still there

The five tabs show the common path. Parameters that change how a result is produced (Settings Sweep, Poisson internals, debug tools) sit in the Advanced zone and in Show Details, out of the way until you need them.

Who It's For

Good fit

  • Photogrammetry of buildings, ruins, monuments and terrain, especially when a laser scan of the same site exists.
  • Heritage documentation and restoration: reconstructions you can measure, and keep identifiable afterwards.
  • Raw scan clean-up: unwelded vertices, junctions, folded flaps, loose debris, zero-area slivers.
  • Objects and artifacts with holes from camera blind spots.

Less suited for

  • Precision CAD. Exact cylinders and planes are better made with Blender's modeling tools or CAD software.
  • Very large patches (beyond roughly 50,000–70,000 faces at once). Patch and Remesh are pure Python, so split big holes into sections. Rebuild, which runs Poisson as a native program, handles large regions far better.
  • Turning a raw point cloud into a whole model. Rebuild reconstructs regions; dedicated photogrammetry software is the right tool for a full model.

Installation

  1. If an earlier version is installed: Edit → Preferences → Add-ons, find MeshVisor, Remove.
  2. Install the .zip: drag it into the Blender window, or Install from Disk in the same menu.
  3. Tick the checkbox to enable it. The panel is in the 3D viewport sidebar (N), tab MeshVisor.

Tested on Blender 4.5 – 5.3. Rebuild uses Michael Kazhdan's PoissonRecon and SurfaceTrimmer (MIT licence). The Windows and Linux builds ship inside the add-on. On macOS, build them from source, then point to them in Settings › Advanced › Rebuild Executables. Check Executables confirms they are found.

Remove the old version before installing a new zip. The add-on is a folder of many files, so installing over an old copy can leave stale files behind.

Reference

The reference is a metric point cloud, usually a laser scan. It is the one thing in the scene that knows real metres, so it never moves: the mesh is fitted onto it (see Reference & Real Scale).

1 — Load the cloud

Load Point Clouds from Folder

Loads every point cloud in a folder (optionally Include Subfolders). Then pick the laser scan as the reference: it is the one at real scale.

Import from Meshroom collapsed

Imports a point cloud (.ply or .abc) or a mesh, textured or plain, straight from Meshroom's output, with no CloudCompare round-trip.

Full-Resolution Source

Link the original, full-density cloud file (binary PLY). Rebuild then reads only the region it needs directly from disk, so the full cloud never has to be loaded into Blender. A light, thinned copy in the scene is enough for viewing and fitting. Source chooses which data Rebuild uses: Referenced (the file) or Loaded (the object in the scene).

2 — Make it readable

ControlWhat it does
Point SizeHow big points are drawn. Only what you see changes.
Viewport ThinningPoints closer than this distance are drawn as one, through a Geometry Nodes modifier. Display only: fitting and Rebuild always use the real points. Apply, Suspend and Reset sit beside it.
Sphere ViewDraws points as small spheres, with an adjustable radius and material, as a workaround for viewport bugs where large clouds drop points.

3 — Crop

Subtraction Volumes

Shapes that cut points out of the full-resolution source (Cut Inside) or keep only what is inside them (Keep Inside Only). Add places a box, Draw drags one out in the viewport, and Convert Selected turns your own meshes into volumes. Preview Exclusion shows the result before anything is final. A Keep Inside Only volume is also how you tell Rebuild which region to reconstruct.

Delete Points in Selection's Bounding Box

Removes points from the real data, not just from the display. Tick the confirmation first.

Align

Fit a mesh to the reference

  1. Select the model (the photogrammetry mesh). The cloud stays put.
  2. Line it up roughly by eye: ICP sharpens an alignment, it cannot find one from nothing.
  3. Fit to Reference. The panel reports the residual and, with Recover Scale on, the scale factor: what one unit of your model is worth in reality.

Limit Scale Change (5% by default) and Limit Movement keep the fit on a leash. After a careful manual placement, a fit that wants to resize by 30% has locked onto the wrong part of the cloud. When a limit is hit, the panel says so.

Advanced

Align multiple scans collapsed

For several scans of the same site, already in real units.

  • Target and Anchor: Chain aligns each scan to the previous one, Fixed Base aligns every scan to the same base.
  • Isolate for Alignment shows only the source and the target, so clicks land where you mean and the viewport is lighter. Exit Isolation brings the scene back. It does not filter the points ICP uses.
  • Align to Target (ICP). Estimate Scale is off by default: scans already share units, and solving scale from partial overlap can drift.
  • Not enough overlap? Mark matching points by hand with the Mark Correspondence Point tool, on the Source, then the Target side, then Align from Marked Points.
  • Lock Pair parents the aligned scan to its target without moving either, so aligning a third scan to the pair later moves both together as one rigid unit.

Repair

One task, three ways in. The small row under the tab switches between them: Rebuild (from the reference cloud), Diagnose (general mesh problems) and Patch (fill a hole without reference data). The panel shows what is marked and selected, and a hint for the next step.

Repair › Rebuild

Rebuilds a damaged region from the measured points rather than inventing geometry across the gap. Around a photogrammetry hole the surface often folds back under itself, so the visible rim is not the topological boundary. Filling the boundary makes a false membrane, and voxel remeshing gets confused. The reference cloud has real measurements there instead.

Needs a reference cloud (Reference) that is fitted to the mesh (Align). The panel tells you if either is missing.

1 — Select the region

  • Rebuild (cloud only, a standalone piece): select a Keep Inside Only crop volume, in Object Mode.
  • Rebuild & Repair (mesh and cloud, continuous with the mesh): also select the mesh, or in Edit Mode the vertices around the hole.

2 — Rebuild

Mark as ReconstructionGives the new patch a distinct, neutral material (colour adjustable). This is the conservation convention, so the fill stays identifiable.

3 — Check, clean up, then Accept or Reject

The patch stays a separate object, already measured: face count, non-manifold edges, and median and 95th-percentile deviation from the reference points. Before accepting, two clean-ups can be run on it, and both are adjustable afterwards with F9:

  • Remove Drips removes the hanging "icicles" Poisson leaves under overhangs and openings.
  • Regularize Walls straightens wall faces, either Keep Relief (the stones stay) or Flatten.

Accept Repair welds the patch into the mesh. Reject throws it away. Nothing is finalized silently.

To compare several reconstructions side by side, use Advanced › Research. The Poisson internals (stick to points, noise averaging, trimming, margins, confidence weighting) are under Show Details and explained in How Rebuild Works.

Fuse with Reference experimental

Moves the mesh onto the reference cloud instead of rebuilding it. Nothing new is built, so there is no patch to trim, review and weld: the mesh keeps its vertices, faces and UVs. In Edit Mode it works on the selected vertices and fades out over a few rings around them (Blend Rings); in Object Mode, on the whole mesh.

  • Each vertex measures how far the cloud is along its normal, and how sure that is. One smooth correction is solved for the whole region; where the cloud has no points, it is carried over from the neighbours, so no step appears where the cloud stops.
  • How much the correction is smoothed is measured from the data. With a noisy cloud the mesh keeps its own detail and only its drift is corrected; with a clean, dense cloud it takes the cloud's detail.
  • Thickness Guard (on): on a thin wall, a face only follows points in the nearer half of the wall, so the side the scanner did not see is not pulled onto the side it did.
  • Holes stay holes: Patch them first, then Fuse pulls the patch onto the cloud. If the cloud reaches fewer than 5% of the vertices, nothing changes and the message says to align first.

Sections experimental

Cuts the selected part of the mesh into parallel slices, every Spacing, so you can see what the mesh and the cloud are doing and correct the mesh by hand. Each slice shows the mesh now (green), the mesh before Fuse (red), the cloud points (grey) and the editable lines (yellow), each with its own on/off button; the arrows step through the slices and the view turns to face each one.

  • Edit Section: move vertices on the yellow lines (for example, push a bulge back into line), or Straighten a run of them. Deleting points (X) removes that part of the mesh, such as a drip hanging in front of a wall.
  • Apply to Mesh: the mesh follows the lines. A moved point pulls firmly, untouched points hold back gently, so the edit stays local. The slices are then cut again from the new mesh.

Repair › Diagnose

Mesh health

Analyze

Scans the mesh once, only when clicked, and summarises holes, junctions, loose geometry and zero-area faces.

Auto Repair

Weld Entire Mesh → Aggressive Auto-Repair of junctions → Analyze, in one go. One Ctrl+Z undoes it all.

Auto Patch Small Holes

Fills every hole whose area is at or below Max Hole Area. That covers the dozens of tiny scan defects, while real openings bigger than the limit are left alone. Scale Factor adjusts the limit when 1 unit ≠ 1 metre.

Smooth Surface

Reduces reconstruction noise on flat areas (walls, floors) without rounding real edges. Edges sharper than the Feature Angle, and every open edge, never move. Controls: Strength, Passes, an optional painted Vertex Group for a feathered transition, and Selected Only.

Repair › Patch

Fills a hole that has no reference data, matching the triangle size, curvature and surface detail around it. Works in Edit Mode.

1 — Mark the hole

Select 1–3 open edges of the hole. Select Full Boundary Loop shows the whole outline, and Mark Hole Boundary stores it on the mesh. Weld Distance merges duplicate vertices first: raw scans often keep a separate vertex per face. If the loop will not close, see Boundary health.

2 — Neighborhood

How far from the rim the analysis looks. 0 m means the first row of faces. A larger radius gives the surface fit more context.

3 — Fill

Clean Hole First on by default

Before filling, removes orphan geometry in and around the marked hole:

  • edges and vertices with no face, such as those left after deleting a larger area with Delete › Only Faces;
  • small loose scraps of faces;
  • fins hanging off a non-manifold edge;
  • faces that cut through their neighbours near the rim.

If removing a face opens a separate small hole, that spot is closed again. Holes elsewhere are never touched. The rim is re-traced afterwards, and the result message lists what was removed.

Choose a Density Mode, Surface Fit, Seam and Material, then Patch. It runs in the background with a progress bar (Refine → Relax → Randomize). Press Esc to cancel.

Stamp — copy wall relief over an element experimental

Photoshop's Patch / Healing Brush, for a wall. For something fixed on a wall that should not be in the model: a pipe, a cable, a lump of ivy, an icicle left by Rebuild. The element is laid flat onto the wall it stands on and the stone relief of another part of the wall is put over it.

  1. Select the faces of the element (with a little of the wall around it).
  2. Pick Source, then click the part of the wall to copy from, as with Alt-click for the Clone Stamp. The 3D cursor marks the spot. The cursor button next to it uses the 3D cursor where it already is.
  3. Stamp Selected Faces. Then adjust in F9:
SettingMeaning
Relief StrengthHow much of the source's relief is laid over. 0 copies nothing: the wall just continues smoothly under the removed element. Use 0 on a survey model, where relief that was not measured there must not appear.
Detail SizeWhat counts as relief (copied from the source) and what counts as the wall's own shape (taken from around the element). About one stone. 0 = automatic: 6 edge lengths of the mesh, at least 15 cm, since a coarse mesh cannot carry shorter relief.
Angle, Mirror, Shift Along / UpTurn, mirror and move the source along the wall, for example to line up the courses.
Heal EdgeBlends the copied relief into the real relief at the edge, so it joins without a step. Off: a plain copy.

Only the vertices inside the selection move; the mesh keeps its faces. Stamped faces get the face attribute mv_stamped = 1, so it stays visible which relief was measured and which was copied. Ctrl+Z undoes it.

Stamp follows one plane: it is for walls, not corners or vaults, and the message warns when the area around the selection is far from flat. It copies the shape, not the colour or texture. If the source overlaps the selection or runs off the mesh, the message says so; move it with Shift Along / Up.

Optimize

Re-adjusts triangle density on the selected faces, usually a fresh patch but any part of the mesh works, relative to the mesh around it, then loosens the result so it does not read as a subdivided grid.

  • Density Mode, Seam and Material: see Density Modes and Seam & Material.
  • Min Triangle Angle (18°): a floor on how thin a triangle may get during edge flips.
  • Geometry Source: by default, Optimize learns size, relief and triangle shapes from the mesh bordering the selection. Pick Geometry Source lets you point at a more representative area instead: hover to preview a circle, scroll to resize it, click to confirm.
  • The face limit per run is in Settings › Performance (20,000 by default).

Advanced › Research

For comparing reconstructions instead of trusting one. Settings Sweep runs Poisson with 2–5 setting combinations on the same crop volume (cloud only) and lays them out side by side. There is no automatic score: a number that rewards "close to the points" favours the noisiest setting, while a person sees blistering or bloating at a glance.

  • Refine Sweep: narrows the range around the variant you click.
  • Preview Variant, Show All, delete or Clear All variants. The history is kept per crop volume.
  • Apply Settings from Selected copies a variant's settings to Rebuild. You can also Save Preset, Load Preset or Export Table (CSV).
  • Weld Selected In Place welds the exact chosen variant into a mesh at its real position, rather than re-running Poisson, which would not land on the same geometry.

Advanced › Diagnostics

Mesh health (Analyze, Auto Repair, Delete Zero-Area Faces) next to Debug Mode and its log: the "why didn't it work" layer, kept out of the normal workflow.

Reference & Real Scale

A photogrammetry reconstruction has an arbitrary scale. A laser scan is metric. MeshVisor therefore treats the cloud as the reference and moves the mesh: it solves rotation, position and, with Recover Scale, a uniform scale. This uses ICP (iterative closest point) with Umeyama's closed-form similarity transform on each pass. A trimmed fraction of the worst matches is ignored, because the two scans never cover exactly the same ground. The recovered factor tells you what one Blender unit of your model is worth in reality.

Points with no normals, which is common in exported clouds, get them estimated: a local plane fit (PCA) for each point's direction, propagated consistently across the patch for which side is out. So there is no mandatory trip through CloudCompare.

How Rebuild Works

Rebuild gathers the cloud's points in the region, plus a ring of good surrounding surface, the Context Margin. Poisson needs real surface all around the gap to know which way is out. It then runs Screened Poisson (Kazhdan & Hoppe) and trims the result with SurfaceTrimmer.

  • Poisson always closes the surface. Where there are no points it invents, and the invention balloons outward. Trimming removes surface below a density threshold. Measure Trim Threshold sets that threshold from the data, or you set it by hand.
  • Stick to Points pulls the surface onto the points. More is not always better: following the points faithfully also follows their noise.
  • Noise Averaging (samples per node) stops the octree from subdividing where it only has noise.
  • Patch Overhang limits how far the finished patch may extend past your selection. Smallest Island drops trimmed confetti. Cloud Points caps how many points are used.
  • Confidence Weighting (optional) lets detailed areas pull harder than flat, noisy ones. It is a heuristic, not a guarantee.

With a Full-Resolution Source linked, the region is read straight from the PLY file on disk, so dense scans do not have to live in the .blend file.

Density Modes

Curvature-Adaptive default

Finer triangles where the real surface around the hole is curved or detailed, coarser where it is flat. Targets are sampled point by point along the rim and diffused inward. It is usually much faster than Uniform, because it makes fewer triangles.

Uniform (Match Neighborhood) slower

One consistent triangle size across the patch, matching the seam. Use it when regularity matters more than speed.

Surface Fit

How the patch is projected onto the real surface around the hole to pick up its curvature and detail.

Project Along Normal default

Follows each point's normal, within a bounded distance. It is fast and reliable on complex terrain.

Nearest Surface

Takes the closest point with no distance limit. It is slower on large neighborhoods. Try it where Project folds in deep crevices.

Seam & Material

Seam

  • Crisp: the join stays exactly as generated.
  • Smooth: a band on both sides of the seam is faired with an iterative bi-Laplacian pass, so the join reads as a transition rather than a line.

Material

  • Blend In: the patch takes the surrounding material.
  • New 'Patch Material': a distinct material, so the repair stays identifiable.

Common Scenarios

Building or ruin: photogrammetry plus a laser scan

Reference: load the clouds, link the full-resolution PLY, thin the display. Align: move the mesh close by eye, then Fit to Reference with Recover Scale. Repair › Rebuild: draw a Keep Inside Only volume over the damage, run Rebuild & Repair, read the deviation, then Accept. For a stubborn area, run a Settings Sweep in Advanced first.

Raw scan, no reference

Repair › Diagnose: Weld Entire Mesh, then Analyze, then Auto Patch Small Holes. Next, Patch each real hole with Clean Hole First on. Optimize the big patches, then Finish.

Heritage object where reconstructions must stay visible

Use Mark as Reconstruction (Rebuild) or New 'Patch Material' (Patch) with a Crisp seam.

Several scans of one site

Align › Align Multiple Scans: Chain or Fixed Base, Isolate for Alignment, ICP. Where overlap is thin, use marked point pairs.

A hole full of leftovers after deleting a damaged area

Mark the new, larger hole and Patch with Clean Hole First on. Orphan edges, scraps and fins inside it are removed before filling.

A pipe, cable or plant on a wall

Select its faces, Pick Source on a clean stretch of the same wall, Stamp Selected Faces. For a survey model, set Relief Strength to 0: the wall continues underneath and nothing is copied.

Debug Mode

In Settings › Advanced, or in Advanced › Diagnostics. While it is on, every operation logs what it did, with timings and the settings used. Patch, Optimize, alignment, Rebuild and Sweep all report there. Copy Log puts it on the clipboard for a bug report. Saved Sessions keep the same log on disk, so it survives a crash.

Glossary

TermMeaning
Reference cloudA metric point cloud (usually a laser scan) used as ground truth for scale, fitting and reconstruction.
ICPIterative closest point: match points, solve the best transform, repeat.
Crop / subtraction volumeA shape that cuts points out of the cloud, or keeps only those inside it.
Screened PoissonA surface reconstruction from oriented points that also pulls the surface onto the points themselves.
Boundary loop · junctionThe ring of open edges around a hole · a point where 3+ open edges meet, which blocks tracing.
Non-manifoldAn edge shared by more than two faces, or other geometry that is not a clean surface.
Orphan geometryEdges and vertices with no face, or scraps of faces not connected to the mesh.
QEMQuadric error metrics: choosing where a collapsed edge lands so the shape changes least.
FairingSmoothing that minimises curvature variation, for a genuinely smooth transition.
